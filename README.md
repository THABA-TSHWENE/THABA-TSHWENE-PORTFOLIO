<h1>🚀 Tebogo Thaba | Professional Portfolio</h1>
    <p>A clean, responsive portfolio showcasing my journey as an IT Graduate and Full-Stack Developer. This project features a modern UI, dark mode functionality, and integrated Cisco professional certifications.</p>

 <h2>🛠️ Tech Stack</h2>
    <p><strong>Frontend:</strong> HTML5, CSS3 (Custom Variables), JavaScript (ES6+)</p>
    <p><strong>Tools:</strong> Boxicons, Formspree (Contact API)</p>
    <p><strong>Styling:</strong> Modern Grid/Flexbox, Glassmorphism, Responsive Design</p>

  <h2>✨ Key Features</h2>
    <p><strong>Dynamic UI:</strong> Includes a smooth typing effect for roles and a custom-designed header.</p>
    <p><strong>Interactive Certifications:</strong> A "slide-up" hover effect for professional certifications (Cisco CCNA & IT Essentials).</p>
    <p><strong>Dark Mode:</strong> A persistent dark mode toggle for better user accessibility.</p>
    <p><strong>Automated Contact:</strong> A functional contact form using Formspree to send messages directly to my email.</p>

  <h2>📜 Certifications Included</h2>
    <p><strong>CCNAv7:</strong> Switching, Routing, and Wireless Essentials.</p>
    <p><strong>IT Essentials:</strong> PC Hardware and Software.</p>
