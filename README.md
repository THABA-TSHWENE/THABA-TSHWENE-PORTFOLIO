🚀 Tebogo Thaba | Professional Portfolio
A clean, responsive portfolio showcasing my journey as an IT Graduate and Full-Stack Developer. This project features a modern UI, dark mode functionality, and integrated Cisco professional certifications.

🛠️ Tech Stack
Frontend: HTML5, CSS3 (Custom Variables), JavaScript (ES6+)

Tools: Boxicons, Formspree (Contact API)

Styling: Modern Grid/Flexbox, Glassmorphism, Responsive Design

✨ Key Features
Dynamic UI: Includes a smooth typing effect for roles and a custom-designed header.

Interactive Certifications: A "slide-up" hover effect for professional certifications (Cisco CCNA & IT Essentials).

Dark Mode: A persistent dark mode toggle for better user accessibility.

Automated Contact: A functional contact form using Formspree to send messages directly to my email.

📜 Certifications Included
CCNAv7: Switching, Routing, and Wireless Essentials.

IT Essentials: PC Hardware and Software.

🚀 How to Run Locally
Clone the repository:

1. git clone https://github.com/THABA-TSHWENE/THABA-TSHWENE-PORTFOLIO.git
2. Open index.html in your browser.
